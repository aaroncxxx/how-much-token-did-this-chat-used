# 📊 How Much Token Did This Chat Used

> 聊天 Token 用量追踪器
> Track Token Usage Per Chat Session

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features / 功能

- 📊 **Token 追踪** — 实时统计每次对话的 Token 消耗
- 💰 **费用估算** — 按模型费率估算成本
- 📈 **趋势分析** — 用量趋势图表
- 🔒 **本地存储** — 数据安全不外泄

## 🚀 Quick Start / 快速开始

```bash
python tracker.py
```
